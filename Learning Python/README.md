# Learning Python

Python 학습 과정 중 Git으로 관리할 가치가 있는 실습 코드, 오류 해결 기록, 장기 복습용 Markdown을 저장하는 폴더입니다. 모든 일일 학습 내용을 자동으로 기록하지 않습니다.

## 학습 지원 원칙

Python 학습 질문에서는 정답 코드부터 제공하지 않습니다.

1. 문제를 작은 단계로 나눈다.
2. 필요한 개념과 접근 방향을 힌트로 제공한다.
3. 개념을 확인할 수 있는 작은 실행 예제와 부분 코드를 제공할 수 있다.
4. 사용자가 직접 작성한 코드를 검토하고, 문제 원인·수정 위치·수정 예시를 설명한다.
5. 막힌 부분에는 힌트, 뼈대 코드, 최소 동작 예제 순서로 도움의 수준을 높인다.
6. 사용자가 명시적으로 요청하거나 충분히 시도한 뒤에도 해결되지 않으면 전체 정답과 이유를 설명한다.
7. 설명이나 정답 뒤에는 직접 다시 해볼 수 있는 짧은 변형 문제를 제안한다.

## 데이터 흐름 중심 설명

반복문, 딕셔너리, 함수처럼 데이터가 이동하는 코드에서는 정답이나 문법 설명보다 먼저 데이터 흐름을 순서대로 설명합니다.

1. 원본 데이터가 어떤 형태인지 확인한다.
2. 반복 또는 함수 호출에서 한 번에 꺼내는 데이터가 무엇인지 확인한다.
3. 꺼낸 데이터가 어떤 변수에 들어가는지 설명한다.
4. 변수에 담긴 값으로 계산·조건 판단·출력을 어떻게 하는지 설명한다.
5. 필요하면 `print()`로 각 단계의 값을 확인하는 작은 예제를 제공한다.

예를 들어 다음 코드는:

```python
for 이름, 점수값 in 점수.items():
```

아래 순서로 설명합니다.

1. `점수.items()`에서 `("민수", 90)`처럼 키와 값이 묶여 나온다.
2. `"민수"`는 `이름` 변수에 들어간다.
3. `90`은 `점수값` 변수에 들어간다.
4. `if 점수값 >= 80`에서 점수를 검사한다.
5. 조건을 통과하면 `print(이름)`으로 이름을 출력한다.

처음에는 필요하면 아래처럼 풀어 쓴 코드로 설명한 뒤, 익숙해지면 짧은 문법으로 정리합니다.

```python
for 묶음 in 점수.items():
    이름 = 묶음[0]
    점수값 = 묶음[1]

    if 점수값 >= 80:
        print(이름)
```

## 코드 보조 방식

직접 시도를 우선하되, 학습 흐름이 끊기지 않도록 질문의 목적과 막힌 정도에 따라 보조합니다.

| 상황 | 지원 방식 |
| --- | --- |
| 개념·문법 질문 | 핵심 설명과 작은 실행 예제 |
| 실습 문제 | 목표·입출력 예시·단계별 힌트 |
| 코드 오류 | 데이터가 들어오는 순서, 변수에 담기는 값, 원인, 수정 위치, 부분 수정 예시 |
| 오래 막힌 경우 | 뼈대 코드 또는 최소 동작 예제 |
| 전체 구현 요청 | 전체 코드, 핵심 이유, 검증 방법, 짧은 변형 문제 |

## 난이도와 창의 응용

문제의 난이도와 코드 보조 수준은 별도로 조절합니다.

| 난이도 | 기준 |
| --- | --- |
| 하 | 배운 개념을 그대로 사용하는 짧은 확인 문제 |
| 중 | 조건을 조합하거나 기존 코드를 수정하는 문제 |
| 상 | 요구사항을 해석하고 구조·예외 처리·여러 개념을 선택하는 문제 |
| 창의 응용 | 같은 개념을 프로젝트나 관심 주제에 새 기능 또는 다른 방식으로 적용하는 과제 |

기본적으로 `하 1개 → 중 1개 → 필요할 때 상 또는 창의 응용 1개` 순서로 연습합니다. 상 난이도와 창의 응용은 핵심 개념을 직접 구현할 수 있을 때 제안하며, 문제 풀이 중에는 문제 이해 힌트부터 전체 해설까지 도움을 단계적으로 제공합니다.
