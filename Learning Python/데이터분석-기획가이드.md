# 데이터분석 기획 가이드

데이터 분석은 명령어를 실행하는 것보다 **무엇을 알고 싶은지 정의하는 일**에서 시작한다. 질문이 분명해야 필요한 데이터와 컬럼, 정제 기준, 집계 방법, 결과물의 형태를 결정할 수 있다.

## 1. 분석 기획의 기본 흐름

```text
문제 정의
→ 분석 질문 작성
→ 분석 대상·범위 결정
→ 필요한 데이터와 컬럼 확인
→ 지표·집계 기준 결정
→ 정제 기준 결정
→ 결과물과 활용 방법 정의
```

## 2. 기획 질문표

분석을 시작하기 전에 다음 항목을 먼저 작성한다.

```text
분석 주제:
해결하려는 문제:
분석 질문:
분석 대상:
한 행이 의미하는 것:
분석 기간:
분석 지역:
측정 단위:
필요한 컬럼:
정제 기준:
사용할 지표:
사용할 집계 함수:
최종 결과물:
예상되는 활용:
데이터의 한계:
```

예를 들어 폐기물 데이터의 지역별 배출량을 분석한다면 다음처럼 구체화한다.

```text
분석 주제: 지역별 폐기물 배출 현황
해결하려는 문제: 배출량이 집중된 지역과 폐기물 종류 파악
분석 질문: 어느 지역의 총배출량이 가장 큰가?
분석 대상: 제공기관별 사업장 기록
한 행이 의미하는 것: 폐기물 배출 업체 한 곳의 기록
필요한 컬럼: 제공기관명, 폐기물분류명, 배출량
사용할 지표: 총배출량, 평균 배출량, 사업장 수
사용할 집계 함수: sum(), mean(), count()
최종 결과물: 지역별 요약표·그래프·인사이트 3문장
```

## 3. 질문을 지표로 바꾸기

| 알고 싶은 것 | 지표 | 집계 |
|---|---|---|
| 전체 양 | 총배출량 | `sum()` |
| 사업장당 일반적인 양 | 평균 배출량 | `mean()` |
| 극단값 영향을 줄인 대표값 | 중앙 배출량 | `median()` |
| 사업장 수 | 기록 개수 | `count()` |
| 종류별 분포 | 분류별 개수 | `value_counts()` |

“가장 많은 지역”은 총량을 비교하는 질문인지, 사업장당 평균을 비교하는 질문인지 먼저 정해야 한다. 같은 데이터라도 지표에 따라 결론이 달라질 수 있다.

## 4. 분석 범위와 데이터 단위 확인

분석 전에 다음을 확인한다.

```text
한 행은 무엇인가?
같은 업체가 여러 행으로 나뉘어 있는가?
기간과 신고 기준 연도가 같은가?
측정 단위가 같은가?
전체 지역을 포함하는가?
```

범위가 다른 자료를 합치거나 비교할 때는 기간·단위·지역 기준을 맞춘다. 기준이 맞지 않으면 계산은 가능해도 해석은 부정확할 수 있다.

## 5. 필요한 컬럼 결정

컬럼은 “있으니까 사용”하지 않고 분석 질문에 필요한 것만 선택한다.

```text
분석 기준 컬럼: 지역, 날짜, 상품 분류 등
계산 컬럼: 가격, 수량, 배출량 등
식별 컬럼: 사업장명, 주문번호 등
설명 컬럼: 주소, 처리방법 등
```

예를 들어 지역별 총배출량에는 `제공기관명`과 `배출량`이 핵심이고, `전화번호`는 필요하지 않다.

## 6. 정제 기준 기획

결측치·중복·이상치는 발견 즉시 삭제하지 않고, 분석 목적에 따라 처리 방법을 정한다.

```text
핵심 지표가 없는 행 → 제외 또는 별도 분류
설명용 컬럼이 없는 행 → 분석 목적에 따라 유지 가능
완전히 같은 레코드 → 중복 여부 확인 후 제거
같은 지역이라는 이유만으로 중복 제거 → 금지
숫자가 아닌 값 → 의미 확인 후 변환·대체·제외
```

## 7. 결과물과 인사이트 기준

결과물은 표 하나로 끝내지 않는다.

```text
관찰: 데이터에서 실제로 무엇이 보이는가?
해석: 그 결과는 무엇을 의미하는가?
활용: 어떤 판단에 사용할 수 있는가?
한계: 어떤 점은 단정할 수 없는가?
```

예시:

```text
관찰: 분석 대상 제공기관 중 A지역의 총배출량이 가장 높다.
해석: 해당 지역에 대규모 배출 사업장 또는 많은 사업장 기록이 포함되었을 수 있다.
활용: 지역별 폐기물 관리 우선순위를 검토할 수 있다.
한계: 제공기관 범위와 신고 기준 연도가 다르면 전국 전체 순위로 단정할 수 없다.
```

## 8. 기획 통과 기준

다음 질문에 답할 수 있으면 코딩 단계로 넘어간다.

```text
무엇을 알고 싶은가?
어떤 행을 분석하는가?
어떤 컬럼이 필요한가?
무엇을 더하거나 비교할 것인가?
어떤 집계 함수를 사용할 것인가?
결과는 누구의 어떤 판단에 도움이 되는가?
결과의 한계는 무엇인가?
```
