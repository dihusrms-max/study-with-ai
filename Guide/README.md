# Guide 운영 규칙

## 폴더 구분

- `current/`: 현재 적용하는 최신 가이드만 보관한다.
- `archive/`: 이전 버전과 폐기된 가이드를 보관한다.
- `setup/`: 개인 PC, 서버, VS Code와 Jupyter 설치 문서를 보관한다.

## 현재 기준

- 실전 기준: `current/나라장터_DACON_AI_경진대회_실전가이드_v1.9_개선전략보완.docx`
- 운영 더블체크: `current/나라장터_DACON_Codex_GPT_더블체크_운영가이드_20260916.docx`
- 자가라벨링 독립 검증 최신안: `current/나라장터_DACON_실전운영가이드_v2.0_자가라벨링독립검증.md`

## 변경 원칙

새 가이드는 먼저 `current/`에 반영하고, 이전 기준은 삭제하지 않고 `archive/`에 보관한다. 공식 대회 규칙이 바뀌면 실전 가이드와 더블체크 문서를 함께 검토한다.
