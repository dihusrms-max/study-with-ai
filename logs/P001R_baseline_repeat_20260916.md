# P001-R 기준선 반복성 검증

## 목적

기존 Gemma API baseline과 동일한 조건으로 dev 200건을 다시 실행하여 다음 Prompt 실험 전에 기준선의 반복성을 확인한다.

## 실행 조건

- 입력: dev 200건
- Prompt: baseline Prompt 그대로
- temperature: 0
- chunk: 4
- timeout: 240초
- retries: 3

## 결과

| 항목 | 기존 baseline | P001-R 반복 |
|---|---:|---:|
| Macro F1 | 0.203517 | 0.209369 |
| JSON 오류 | 0 | 0 |
| 누락 항목 | 0 | 0 |
| 실행시간 | 기존 기록 참조 | 1,729.1초 (약 28분 49초) |
| 24개 항목 전체 동일 예측 | - | 108/200건 |
| 변경된 항목 판정 수 | - | 137건 |

v13 오탐은 85→83, v17 오탐은 52→59로 변해 안정적인 개선으로 볼 수 없었다.

## 판단

P001-R의 Macro F1은 기존 baseline보다 0.005852 높았지만, 200건 중 전체 24개 판정이 동일한 건은 108건에 그쳤다. 이번 점수 상승을 Prompt 개선 효과로 해석하지 않는다.

다음 Prompt 실험은 보류한다. 먼저 API 응답 변동성의 원인을 확인하고 기준선 반복 결과를 통제하는 기준을 정한 뒤 v13 단독 Prompt 실험을 진행한다.
