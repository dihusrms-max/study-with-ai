# Pandas로 폐기물 배출 데이터 정제하고 지역별 배출량 분석하기

CSV 데이터를 분석할 때는 바로 `groupby()`부터 적용하기보다, 데이터의 구조와 결측치, 중복 기준을 먼저 확인해야 한다. 이번에는 전국 폐기물 배출 업체 표준 데이터를 사용해 지역별 총배출량과 지역별 주요 폐기물 종류를 분석하는 흐름을 정리했다.

## 분석 질문 정하기

분석 질문을 먼저 정하면 어떤 열을 남기고, 어떤 결측치를 처리해야 할지 결정하기 쉬워진다.

1. 제공기관별 총배출량은 얼마인가?
2. 각 제공기관에서 배출량이 가장 큰 폐기물 분류는 무엇인가?
3. 전체 데이터에서 배출량이 큰 폐기물 분류는 무엇인가?

## CSV 읽기와 기본 점검

한글 CSV는 저장 인코딩에 따라 읽기 옵션이 달라진다. 이번 파일은 `cp949`로 읽었다.

```python
import pandas as pd

waste_df = pd.read_csv(
    "../data/전국폐기물배출업체표준데이터.csv",
    encoding="cp949"
)
```

불러온 뒤에는 `head()`, `info()`, `dtypes`, `isna().sum()`으로 데이터 구조와 결측치를 점검한다. `info`와 `describe`는 메서드이므로 반드시 괄호를 붙여 `info()`, `describe()`처럼 실행해야 한다.

```python
waste_df.info()
waste_df.isna().sum()
```

## 분석에 필요한 열만 선택하기

이번 분석에 필요한 핵심 열은 지역, 폐기물 분류, 배출량이다.

```python
analysis_df = waste_df[
    ["제공기관명", "폐기물분류명", "배출량"]
].copy()
```

`df["배출량"]`은 하나의 열을 선택해 Series를 반환한다. 여러 열을 선택할 때는 열 이름을 리스트로 전달하므로 `df[["열1", "열2"]]` 형태가 된다.

## 결측치와 중복 기준은 분석 목적에 맞게 정한다

지역별 총배출량에는 `제공기관명`과 `배출량`이 반드시 필요하다. 따라서 이 두 열의 결측치를 먼저 확인한다.

```python
analysis_df[["제공기관명", "배출량"]].isna().sum()
```

중복 제거에서 주의할 점도 있다.

```python
analysis_df.drop_duplicates(subset="제공기관명")
```

위 코드는 지역마다 첫 행만 남긴다. 지역별 배출량 합계를 구해야 하는 상황에서는 같은 지역의 다른 사업장 기록까지 제거하므로 부적절하다. 원본의 완전히 같은 행인지 확인하고, 필요한 경우에만 전체 행 기준 중복을 제거해야 한다.

```python
waste_df.duplicated().sum()
```

## 지역별 총배출량 집계

`groupby()`로 제공기관별로 묶은 뒤 `sum()`으로 배출량을 더한다. 정렬은 집계 후에 적용한다.

```python
region_sum_df = (
    analysis_df
    .groupby("제공기관명", as_index=False)["배출량"]
    .sum()
    .sort_values("배출량", ascending=False)
)
```

여기서 `as_index=False`를 사용하면 `제공기관명`이 인덱스가 아니라 일반 컬럼으로 남아 이후 조회와 시각화에 편하다.

`sum()`, `mean()`, `median()`은 서로 다른 질문에 답한다.

| 함수 | 답하는 질문 |
| --- | --- |
| `sum()` | 해당 지역의 전체 배출량은 얼마인가? |
| `mean()` | 해당 지역에서 사업장 한 곳당 평균 배출량은 얼마인가? |
| `median()` | 극단값을 줄였을 때 대표적인 사업장 배출량은 얼마인가? |

## 지역별 주요 폐기물 찾기

지역과 폐기물 분류를 함께 묶어 배출량을 더한 뒤, 지역 안에서 배출량이 큰 항목을 위로 정렬한다. 각 지역의 첫 행이 해당 지역의 주요 폐기물 분류가 된다.

```python
region_category_df = (
    analysis_df
    .groupby(["제공기관명", "폐기물분류명"], as_index=False)["배출량"]
    .sum()
    .sort_values(
        by=["제공기관명", "배출량"],
        ascending=[True, False]
    )
)

region_top_category_df = (
    region_category_df
    .groupby("제공기관명")
    .head(1)
)
```

`head(1)`은 각 지역 그룹의 첫 행을 가져온다. 따라서 반드시 지역별 배출량 내림차순 정렬을 먼저 해야 한다.

## 분석 결과를 해석할 때의 주의점

집계 결과는 데이터에 포함된 제공기관과 신고 기준 연도의 기록을 요약한 것이다. 따라서 제공기관 수와 연도 범위를 확인하지 않은 채 결과를 전국 전체의 현재 순위라고 단정하면 안 된다.

분석 문장은 다음처럼 범위를 포함해 작성하는 편이 정확하다.

> 분석 대상 제공기관 데이터에서는 사업장폐기물의 배출량이 큰 비중을 보였다. 지역별 배출량과 주요 폐기물 분류를 함께 확인하면, 지역마다 어떤 폐기물 관리 항목을 우선적으로 살펴봐야 하는지 파악할 수 있다.
