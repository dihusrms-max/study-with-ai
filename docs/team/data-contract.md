# 팀 공통 입출력 계약

모든 후보와 `main`은 아래 계약을 만족해야 한다. 계약이 다른 후보는 점수 비교 전에 어댑터를 만든다.

## 입력

- 입력 경로와 파일명은 실행 옵션으로 받는다. 코드에 개인 PC 경로를 하드코딩하지 않는다.
- 원문 데이터는 Git에 저장하지 않는다.
- 각 행을 식별할 수 있는 공고 ID를 보존한다.
- 입력 컬럼 목록과 데이터 버전은 실행 로그에 기록한다.

## 출력

- 공고 ID와 `v1`~`v24` 판정 컬럼을 반드시 포함한다.
- 행 수와 공고 ID 집합은 입력과 일치해야 한다.
- 판정값은 대회 제출 형식에 맞는 허용값만 사용한다.
- 근거문구가 필요한 경우 원문에서 그대로 추출한 부분문자열만 사용한다.
- 근거문구는 500자 이하로 제한하고, 해당 사항이 없으면 빈칸으로 둔다.
- 파일 인코딩, 구분자, 컬럼 순서는 `validate_submission.py`에서 검사한다.

## 실행 기록

다음 정보를 결과 파일 또는 로그에 남긴다.

- Git 커밋 또는 태그
- 프롬프트 버전
- 모델명과 호출 설정
- Python 및 주요 패키지 버전
- 실행 시각과 random seed
- 사용한 데이터 버전
