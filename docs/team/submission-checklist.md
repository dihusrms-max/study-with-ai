# 제출 전 체크리스트

- [ ] 제출 버전 태그를 만들었다.
- [ ] 태그의 커밋과 제출 파일이 일치한다.
- [ ] 공통 채점기로 dev 200건을 다시 실행했다.
- [ ] 출력 행 수와 공고 ID가 입력과 일치한다.
- [ ] `v1`~`v24` 컬럼과 값 형식을 검증했다.
- [ ] 근거문구가 원문 부분문자열이며 500자 이하인지 확인했다.
- [ ] 외부 데이터와 학습 모델을 사용하지 않았는지 확인했다.
- [ ] 고정 LLM 호출 횟수와 프롬프트 버전을 기록했다.
- [ ] API 키와 개인정보가 포함되지 않았는지 확인했다.
- [ ] 제출 담당자와 제출 예정 시각을 대장에 기록했다.
- [ ] 제출 후 LB 점수, 날짜, 버전, 제출자를 기록한다.
