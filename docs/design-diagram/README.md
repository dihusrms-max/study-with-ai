# Design Diagrams

프로젝트 문서와 학습 자료에 사용하는 다이어그램 산출물을 보관한다.

## 저장 원칙

- `design-skill/diagram-design-main`의 diagram-design 규칙을 따른다.
- 기본 산출물은 self-contained HTML이다.
- SVG/PNG는 사용 목적이 명확할 때만 HTML에서 export한다.
- 파일명은 `YYYY-MM-DD-주제-유형` 또는 프로젝트 단위의 명확한 slug를 사용한다.
- Data Inspector 관련 다이어그램은 원본 데이터나 분석 결과를 변경하지 않고 설명 목적으로만 작성한다.

## 권장 하위 구분

- `data-inspector/`: 검사·검증·결합 흐름
- `learning/`: Python·Pandas 개념과 학습 흐름
- `project/`: 프로젝트 구조·아키텍처·로드맵
