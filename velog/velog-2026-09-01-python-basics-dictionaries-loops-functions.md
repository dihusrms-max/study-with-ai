# Python 기초 학습 정리: 딕셔너리, 반복문, 함수

오늘은 Python의 자료형과 딕셔너리, 반복문, 조건문, 함수를 중심으로 학습했다. 특히 딕셔너리에서 값을 꺼내는 방법과 `for`문을 언제 써야 하는지 정리할 수 있었다.

## 딕셔너리에서 값 꺼내기

딕셔너리에 특정 키의 값이 필요하다면 키를 이용해 바로 가져오는 것이 좋다.

```python
데이터 = {"체중": 62, "키": 166}

체중 = 데이터["체중"]
키 = 데이터["키"]
```

`.values()`는 모든 값을 반복할 때 사용한다.

```python
지출내역 = {"커피": 5000, "점심": 10000, "교통비": 1500}

합계 = 0

for 금액 in 지출내역.values():
    합계 += 금액

print(합계)
```

키와 값을 모두 사용해야 한다면 `.items()`를 사용한다.

```python
점수 = {"민수": 90, "지현": 55, "수호": 100, "예린": 88}

for 이름, 점수값 in 점수.items():
    if 점수값 >= 80:
        print(이름)
```

## `append()`와 `print()`의 차이

`append()`는 리스트에 값을 저장하고, `print()`는 화면에 출력한다.

```python
data = []

for i in range(1, 6):
    result = i ** 2
    print(result)
    data.append(result)
```

주의할 점은 `print()`의 결과를 리스트에 넣을 수 없다는 것이다.

```python
data.append(print("안녕하세요"))
```

위 코드는 `안녕하세요`를 출력하지만 리스트에는 `None`이 들어간다.

## 리스트 컴프리헨션

반복문으로 새 리스트를 만드는 코드는 리스트 컴프리헨션으로 간단하게 작성할 수 있다.

```python
data = [i ** 2 for i in range(1, 6)]
```

조건도 추가할 수 있다.

```python
짝수 = [i for i in range(1, 11) if i % 2 == 0]
```

복잡한 로직이라면 일반 `for`문이 읽기 더 편할 수 있다.

## 함수로 BMI 계산하기

BMI 계산처럼 여러 번 사용할 로직은 함수로 만들 수 있다.

```python
def bmi_calculator(데이터):
    키_m = 데이터["키"] / 100
    return 데이터["체중"] / (키_m ** 2)


사람 = {"체중": 62, "키": 166}

결과 = bmi_calculator(사람)
print(f"BMI: {결과:.1f}")
```

함수를 작성할 때는 데이터를 함수 안에서 새로 만들기보다, 함수 밖에서 만든 데이터를 매개변수로 전달하는 방식이 재사용하기 좋다.

## 마무리

오늘 학습의 핵심은 다음과 같다.

- 특정 값은 `딕셔너리["키"]`로 가져온다.
- 모든 값을 반복할 때 `.values()`를 사용한다.
- 키와 값을 함께 반복할 때 `.items()`를 사용한다.
- `print()`는 출력, `append()`는 저장이다.
- 반복해서 사용할 계산은 함수로 만든다.
