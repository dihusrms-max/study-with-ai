# 지하철 이용량과 혼잡도 데이터를 분석하기 전에 확인할 것

## 들어가며

지하철 이용량과 혼잡도를 함께 분석하려면 그래프를 그리기 전에 데이터의 구조와 분석 단위를 맞춰야 한다. 이용량이 많은 역이 반드시 가장 혼잡한 역이라고 단정할 수 없기 때문이다.

이번 학습에서는 시간대별 혼잡도, 역별 평균 혼잡도, 이용객 수와 혼잡도의 관계를 분석 질문으로 설정했다.

## 먼저 데이터 구조 확인하기

```python
df.head()
df.shape
df.columns
df.info()
df.isna().sum()
```

서로 다른 파일을 결합하기 전에 컬럼명, 자료형, 결측치, 한 행의 의미를 확인해야 한다. 이용량 데이터와 혼잡도 데이터는 시간·역·노선·방향의 기준이 다를 수 있다.

## 분석 단위 나누기

```text
시간대별 집계 → 언제 혼잡한가?
역별 집계     → 어느 역이 혼잡한가?
노선별 집계   → 어느 노선의 혼잡도가 높은가?
```

총 이용객 수와 혼잡도는 같은 지표가 아니다. 이용객 수는 전체 이용 규모를 보여주고, 혼잡도는 수송 여건과 특정 시간대 집중 현상을 반영한다.

## Plotly로 대화형 그래프 구성하기

```python
import plotly.express as px

fig = px.bar(
    summary_df,
    x="시간대",
    y="평균혼잡도",
    text_auto=".1f",
    title="시간대별 평균 혼잡도",
    template="plotly_white"
)

fig.update_traces(textposition="outside")
fig.update_layout(title_x=0.5)
fig.show()
```

Plotly는 마우스 오버, 확대·이동, 값 확인이 가능하다. 여러 그래프를 한 화면에 배치하면 시간대별 혼잡도, 역별 평균, 이용량과 혼잡도의 관계를 대시보드로 구성할 수 있다.

## 데이터 결합 시 주의점

공통 컬럼이 `호선`, `역명`이라고 해서 바로 `merge()`하면 안 된다. 한쪽은 날짜 × 호선 × 역, 다른 쪽은 요일 × 호선 × 역 × 시간대일 수 있기 때문이다.

```text
목표 분석 단위 결정
→ 각 데이터의 Grain 확인
→ 역명·노선명 표기 정리
→ 필요한 수준으로 집계
→ Key 중복 확인
→ merge 후 행 수와 미매칭 Key 검증
```

## 마무리

지하철 혼잡도 분석에서는 시각화보다 먼저 분석 질문과 집계 기준을 정해야 한다. 이용량이 많다는 사실은 혼잡 가능성을 보여주는 단서일 뿐이며, 시간대·역·노선·방향을 동일한 기준으로 맞춘 뒤 해석해야 한다.
