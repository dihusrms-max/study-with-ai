# 리스트·튜플·딕셔너리를 다루며 만난 파이썬 초반 오류들

파이썬을 처음 익힐 때는 문법 자체보다, 값과 함수 이름을 구분하는 과정에서 오류를 자주 만난다. 오늘은 가격 목록과 점수표를 예시로 리스트, 튜플, 딕셔너리를 다루면서 자주 발생하는 오류와 해결 방법을 정리했다.

## 리스트에 값 추가하고 평균 구하기

리스트에는 `append()`로 새 값을 추가할 수 있다. 개수와 합계는 각각 `len()`과 `sum()`으로 구하고, 평균은 합계를 개수로 나누면 된다.

```python
가격 = [1200, 3400, 900]
가격.append(2500)

개수 = len(가격)
합계 = sum(가격)
평균 = 합계 / 개수

print(평균)  # 2000.0
```

`average = average(sum / len)`처럼 작성하면 `average()`라는 함수를 호출하려고 시도한다. 평균을 저장할 변수와 평균을 계산하는 식은 다르므로 `평균 = 합계 / 개수`처럼 분리해야 한다.

## 내장 함수 이름을 변수로 쓰면 생기는 문제

다음처럼 작성하면 처음에는 실행되는 것처럼 보일 수 있다.

```python
len = len(가격)
```

하지만 실행 뒤 `len`은 함수가 아니라 정수 변수가 된다. 이후 `len(가격)`을 실행하면 아래 오류가 발생한다.

```text
TypeError: 'int' object is not callable
```

`sum`, `list`도 같은 문제를 만들 수 있다. 특히 Jupyter Notebook은 이전 셀의 변수를 유지하므로 오류가 계속 남아 보일 수 있다. 이때는 커널을 재시작하거나, 덮어쓴 이름을 삭제해 내장 함수를 복구한다.

```python
del len
del sum
del list
```

처음부터 `개수`, `합계`, `리스트`처럼 역할이 드러나는 변수명을 사용하면 충돌을 예방할 수 있다.

## 튜플을 리스트로 바꾼 뒤 값 꺼내기

튜플은 수정할 수 없는 자료형이지만 `list()`를 사용하면 리스트로 변환할 수 있다.

```python
날짜 = (2026, 3, 15)
리스트 = list(날짜)

print(리스트[0])  # 2026
```

각 값을 한 번에 변수에 나누어 담는 언패킹도 가능하다.

```python
년, 월, 일 = list(날짜)
print(f"{년}년 {월}월 {일}일")
```

중요한 점은 튜플 전체를 먼저 변환해야 한다는 것이다. `list(날짜[0])`는 숫자 하나를 리스트로 바꾸려는 코드이므로 오류가 난다.

## 딕셔너리는 키로 값을 찾는다

딕셔너리는 객체 속성처럼 점(`.`)으로 값을 꺼내지 않는다. 키를 대괄호 안에 넣는다.

```python
가격표 = {"우유": 2500, "빵": 3000, "계란": 5000}

총액 = 가격표["우유"] * 2 + 가격표["빵"] + 가격표["계란"]
할인가 = 총액 * 0.9

print(총액)    # 13000
print(할인가)  # 11700.0
```

여기서 `"우유"`는 문자열 키다. 따옴표 없이 `가격표[우유]`라고 쓰면 파이썬은 `우유`라는 변수를 찾는다. `가격표.우유`는 딕셔너리에 없는 속성을 찾는 문법이므로 `AttributeError`가 발생한다.

## 딕셔너리 값 수정·추가와 점수 계산

딕셔너리의 기존 값은 대입으로 수정하고, 없는 키에 대입하면 새 항목이 추가된다.

```python
점수 = {"국어": 90, "영어": 85, "수학": 100}

점수["영어"] = 95  # 수정
점수["과학"] = 80  # 추가
```

점수만 모아 계산하려면 `values()`를 사용한다.

```python
총점 = sum(점수.values())
평균 = 총점 / len(점수)
최고점 = max(점수.values())

print(총점, 평균, 최고점)
# 365 91.25 100
```
