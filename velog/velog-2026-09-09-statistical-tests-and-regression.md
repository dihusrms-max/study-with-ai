# 통계검정부터 효과크기·비모수 검정·선형회귀까지 분석 흐름 정리하기

## 들어가며

데이터에서 차이나 관계가 보인다고 해서 바로 의미 있는 결과라고 판단할 수는 없다. 이번 학습에서는 따릉이와 상권 매출 데이터를 이용해 가설검정의 원리, 효과크기, 비모수 검정, 선형회귀를 연습했다.

통계 분석의 목적은 숫자를 계산하는 데 그치지 않고, 더 나은 판단과 의사결정을 돕는 데 있다.

## 가설검정의 기본

- 귀무가설: 차이나 관계가 없다는 기본 가정
- 대립가설: 차이나 관계가 있다는 가정
- p-value: 귀무가설이 맞다고 가정했을 때 현재 결과가 나타날 가능성

일반적으로 `p-value < 0.05`이면 귀무가설을 기각할 근거가 있다고 판단한다. 유의수준 0.05는 실제로 차이가 없는데 있다고 판단하는 1종 오류를 5%까지 감수하겠다는 기준으로 이해할 수 있다. 반대로 차이가 있는데 없다고 판단하는 것은 2종 오류다.

다만 p-value만으로 차이의 크기나 업무적 중요성까지 알 수는 없다. 표본이 크면 작은 차이도 유의하게 나올 수 있으므로 효과크기를 함께 확인해야 한다.

## t검정: 평균 차이 확인하기

t검정은 “두 그룹의 평균이 다른가?” 또는 “한 그룹의 평균이 특정 기준과 다른가?”라는 질문에 사용한다.

```python
# 일표본 t검정: 평균 이용건수가 40건과 다른가?
t, p = stats.ttest_1samp(data["이용건수"], 40)

# 독립표본 t검정: 서로 다른 두 그룹의 평균 비교
t, p = stats.ttest_ind(
    male_time,
    female_time,
    equal_var=False
)

# 대응표본 t검정: 같은 상권의 주중·주말 평균 비교
t, p = stats.ttest_rel(
    market["주중_매출_금액"],
    market["주말_매출_금액"]
)
```

일표본은 기준값과 비교하고, 독립표본은 서로 다른 대상의 두 그룹을 비교한다. 대응표본은 같은 대상의 두 조건을 비교하므로 데이터의 짝이 유지되어야 한다. 독립표본 t검정에서는 두 그룹의 분산이 같다고 가정하기 어려운 경우 `equal_var=False`를 사용할 수 있다.

## 그룹 수와 변수 형태에 따른 선택

| 질문 | 후보 방법 |
| --- | --- |
| 두 그룹 평균 비교 | t검정 또는 Mann–Whitney U |
| 세 그룹 이상 평균 비교 | ANOVA 또는 Kruskal–Wallis |
| 범주형 변수 간 관련성 | 카이제곱 검정 |
| 숫자형 변수 간 순위 관계 | Spearman 상관분석 |
| 여러 변수로 목표값 예측 | 선형회귀 |

ANOVA에서 유의한 결과가 나오면 모든 상권의 평균 매출이 같다고 보기는 어렵다는 뜻이다. 하지만 어느 그룹 사이에 차이가 있는지는 ANOVA만으로 알 수 없으므로 사후검정이 필요하다. 데이터가 정규성이나 등분산성 조건을 충족하지 못하면 비모수 검정을 고려한다.

## 카이제곱 검정: 범주형 변수의 관련성

성별과 연령대처럼 범주형 변수 사이의 관련성을 확인할 때 교차표를 만들고 관측빈도와 기대빈도를 비교한다.

```python
table = pd.crosstab(data["성별"], data["연령대코드"])
chi2, p, dof, expected = stats.chi2_contingency(table)
```

관측빈도가 기대빈도와 크게 다르면 두 범주가 독립적이지 않을 가능성을 검토한다. 기대빈도가 지나치게 작으면 결과를 신중하게 해석하거나 다른 방법을 검토해야 한다.

## 효과크기: 차이가 얼마나 큰가

두 집단의 평균 차이를 검정할 때는 p-value와 함께 Cohen's d를 확인할 수 있다. Cohen's d는 평균 차이를 합동 표준편차로 나눈 값이다.

```python
import numpy as np

male = data.loc[data["성별"] == "M", "이용건수"]
female = data.loc[data["성별"] == "F", "이용건수"]

t, p = stats.ttest_ind(male, female, equal_var=False)

pooled_std = np.sqrt(
    ((len(male) - 1) * male.var()
     + (len(female) - 1) * female.var())
    / (len(male) + len(female) - 2)
)
d = (male.mean() - female.mean()) / pooled_std
```

학습 기준에서는 대략 `0.2`를 작은 효과, `0.5`를 중간 효과, `0.8`을 큰 효과로 해석했다. 실제로는 분야와 맥락에 따라 기준이 달라질 수 있다. p-value가 유의해도 Cohen's d가 작다면 통계적으로는 차이가 있지만 실질적인 차이는 작을 수 있다.

## 비모수 검정: 분포가 치우친 데이터 다루기

상권 매출처럼 값이 한쪽으로 크게 치우친 데이터는 평균과 정규성 가정에 의존하는 검정이 적절하지 않을 수 있다. 비모수 검정은 원자료의 값보다 순위를 이용해 비교한다.

### Mann–Whitney U

서로 독립인 두 그룹을 비교할 때 사용한다. 예를 들어 관광특구와 골목상권의 매출 분포를 비교할 수 있다.

```python
u, p = stats.mannwhitneyu(tourism, street)
```

평균만 보지 않고 중앙값과 함께 확인하면 치우친 분포를 더 잘 설명할 수 있다.

### Wilcoxon signed-rank

같은 대상의 두 조건을 비교할 때 사용하는 대응표본 t검정의 대안이다. 같은 상권의 주중 매출과 주말 매출처럼 짝이 있는 데이터를 비교할 수 있다.

```python
w, p = stats.wilcoxon(
    df["주중_매출_금액"],
    df["주말_매출_금액"]
)
```

### Kruskal–Wallis

세 그룹 이상을 비교할 때 사용하는 ANOVA의 비모수 대안이다.

```python
groups = [
    group["당월_매출_금액"].values
    for _, group in df.groupby("상권_구분_코드_명")
]
h, p = stats.kruskal(*groups)
```

Kruskal–Wallis에서 유의한 결과가 나온 뒤에는 어떤 그룹 사이에 차이가 있는지 추가 비교가 필요하다.

## 선형회귀: 관계를 예측식으로 표현하기

선형회귀는 설명변수와 목표변수의 관계를 식으로 나타낸다. 상권 매출 데이터에서는 매출 건수로 매출 금액을 예측하는 질문을 만들 수 있다.

```python
from scipy import stats

r = stats.linregress(
    df["당월_매출_건수"],
    df["당월_매출_금액"]
)

target_sales = 200_000_000
need_count = (target_sales - r.intercept) / r.slope
```

기울기와 절편으로 회귀식을 만들면 목표 매출에 필요한 예상 매출 건수를 계산할 수 있다. `sns.regplot()`을 이용하면 산점도와 회귀선을 함께 확인할 수 있다.

설명변수가 여러 개라면 statsmodels의 OLS를 사용할 수 있다.

```python
import statsmodels.formula.api as smf

model = smf.ols(
    "시험점수 ~ 공부시간 + 용돈",
    data=study_df
).fit()

model.rsquared
model.params
model.pvalues
```

`R²`는 모델이 목표변수의 변동을 얼마나 설명하는지 보여주고, `params`는 변수별 계수, `pvalues`는 계수의 통계적 유의성을 확인하는 데 사용한다.

회귀 오차를 평가할 때는 SSE(오차 제곱의 합), MSE(평균 제곱 오차), MAE(절대 오차의 평균), RMSE(평균 제곱근 오차) 같은 지표를 사용할 수 있다.

범주형 변수는 필요에 따라 원-핫 인코딩 등으로 변환해 모델에 입력한다. 회귀식이 계산된다고 해서 인과관계가 증명되는 것은 아니므로, 데이터 수집 방식과 분석 범위를 함께 확인해야 한다.

## 마무리

통계검정은 질문에 따라 선택해야 한다. 두 독립 그룹이면 t검정 또는 Mann–Whitney U, 대응되는 두 조건이면 대응 t검정 또는 Wilcoxon, 세 그룹 이상이면 ANOVA 또는 Kruskal–Wallis를 검토한다. 범주형 변수 간 관련성에는 카이제곱 검정을 사용한다.

최종 해석에서는 통계량, p-value, 효과크기, 데이터 분포와 검정 조건, 실제 업무 맥락을 함께 기록해야 한다. “유의한가?”와 “얼마나 큰가?”, “그래서 어떤 결정을 할 수 있는가?”는 서로 다른 질문이다.
