# 2026-09-08 일일 학습 보고

## 오늘 새롭게 이해한 것

- Plotly는 마우스 오버, 확대·이동, 값 표시가 가능한 반응형 시각화를 만들 수 있다.
- 여러 그래프를 한 화면에 배치하면 분석 결과를 대시보드 형태로 구성할 수 있다.
- 데이터 분석에서는 `head()`, `shape`, `columns`, `info()`, `isna().sum()`으로 데이터 구조와 결측치를 먼저 확인해야 한다.
- 지하철 이용 데이터와 혼잡도 데이터를 분석할 때는 시간대별, 역별, 노선별 기준을 분리해 집계해야 한다.
- 총 이용객 수와 혼잡도는 서로 다른 지표이므로 하나의 값만으로 혼잡한 역이나 시간을 단정할 수 없다.

## 아직 애매하거나 복습할 것

- 시간대별 혼잡도와 역별 평균 혼잡도를 각각 어떤 질문에 활용할지 구분하기.
- 이용객 수와 혼잡도 사이의 상관관계를 인과관계로 해석하지 않는 방법 복습하기.
- 날짜가 다른 데이터나 조사 기준이 다른 데이터를 함께 분석할 때 비교 가능한 범위를 정하기.

## 직접 해본 것

- 여러 그래프를 한 화면에 배치하는 대시보드 구조를 연습했다.
- 따릉이 및 지하철 데이터의 행·열 수, 컬럼명, 자료형, 결측치를 확인했다.
- 지하철 이용정보, 환승인원, 시간대별 혼잡도 데이터를 불러오고 컬럼 구조를 비교했다.
- 시간대별 혼잡도, 역별 평균 혼잡도, 이용객 수와 혼잡도의 관계를 분석하기 위한 DataFrame 구조를 구성했다.

## 오늘의 핵심 인사이트
