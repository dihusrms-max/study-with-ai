## 오늘 새롭게 이해한 것

### 파일에 내용을 작성하고 읽는 방법

- 파일에 문자열을 저장할 때는 `write()`를 사용한다. `write()`는 문자열을 인자로 받아야 하며, 반환값은 저장한 내용이 아니라 작성한 글자 수다.
- 파일 모드 `"w"`는 기존 내용을 지우고 새로 작성하며, `"a"`는 기존 내용 뒤에 추가하고, `"r"`은 파일을 읽는다.
- 여러 문장을 파일에 저장할 때는 리스트와 `for`문을 사용한다. 반복할 때 `text`는 리스트에서 하나씩 꺼낸 문장이다.
- 파일을 한 줄씩 읽을 때는 `for line in file:`처럼 파일 객체를 반복한다. `line.strip()`은 줄 끝의 줄바꿈과 불필요한 공백을 제거한다.

```python
texts = ["시간은 금이다", "배움에는 끝이 없다"]

with open("myeong-eon.txt", "a", encoding="utf-8") as file:
    for text in texts:
        file.write(text + "\n")
```

### 리스트·튜플과 함수 반환값

- `append()`는 리스트에 값을 추가하는 메서드다. 파일에는 `append()`가 없으므로 파일에 내용을 추가할 때는 `"a"` 모드와 `write()`를 사용한다.
- 튜플도 `for`문으로 항목을 하나씩 꺼낼 수 있지만, 만든 뒤에는 값을 수정하거나 `append()`로 추가할 수 없다.
- `*nums`는 여러 개의 위치 인수를 하나의 튜플로 받는다.
- `min()`과 `max()`는 내장 함수이고, `append()`는 리스트 메서드다.
- 함수는 값 하나뿐 아니라 여러 값을 반환할 수 있다. `최소, 최대 = 최소최대([...])`처럼 반환값 두 개를 각각의 변수로 나누어 받을 수 있다.

```python
def 최소최대(nums):
    return min(nums), max(nums)


최소, 최대 = 최소최대([3, 7, 1, 9])
```

### 예외 처리와 `return`

- `try` 블록에서 정상 실행될 때 값을 반환하고, `except` 블록에서 오류가 발생했을 때 다른 값을 반환할 수 있다.
- 두 경우 모두 `return`이 있으면 함수 마지막에 별도의 `return`은 필요 없다.
- 필요한 오류만 처리하도록 `except ZeroDivisionError:`처럼 예외 유형을 구체적으로 작성하는 것이 좋다.

```python
def 안전나눗셈(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return None
```

### 클래스, 객체, `self`

- 클래스는 객체를 만들기 위한 설계도이고, 객체는 클래스로 만든 실제 대상이다.
- `학생1 = 학생("김민수", 24)`는 `학생` 클래스로 객체를 만들고 그 객체를 `학생1` 변수에 저장한다.
- `self`는 현재 생성하거나 사용 중인 객체를 가리키는 참조다. 여러 객체를 만들 때 각 객체의 속성을 구분해 저장하고 사용하도록 한다.
- `self.이름 = 이름`에서 오른쪽 `이름`은 함수 매개변수이고, 왼쪽 `self.이름`은 객체 안에 저장되는 속성이다.
- 객체 생성 때 값을 저장했다면 메서드에서 이름과 나이를 다시 매개변수로 받을 필요 없이 `self.이름`, `self.나이`로 가져온다.

```python
class 학생:
    def __init__(self, 이름, 나이):
        self.이름 = 이름
        self.나이 = 나이

    def introduce(self):
        print(f"{self.이름}입니다. {self.나이}살이에요.")


학생1 = 학생("김민수", 24)
학생1.introduce()
```

## 아직 애매하거나 복습할 것

- `self`를 메모리 주소 자체가 아니라 현재 객체를 가리키는 참조로 설명할 수 있는지 다시 확인한다.
- 메서드의 매개변수와 객체 속성의 차이를 구분한다. 생성 시 저장한 값은 메서드에서 `self.속성`으로 사용한다.
- `"w"`와 `"a"` 모드의 차이를 실제 파일에 각각 적용해 확인한다.
- `return`과 `print()`의 역할을 구분한다. `return`은 결과를 호출한 곳으로 전달하고, `print()`는 화면에 보여 준다.
