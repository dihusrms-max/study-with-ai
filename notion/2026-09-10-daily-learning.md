# 2026-09-10 일일 학습 보고

## 오늘 새롭게 이해한 것

- 데이터 분석은 Pandas 함수를 바로 실행하기보다 분석 목적, 질문, 범위, 지표, 한 행의 의미를 먼저 정의해야 한다.
- 데이터 결합 전에는 각 데이터의 Grain과 Key 후보를 확인해야 하며, 공통 컬럼이 있다는 이유만으로 바로 `merge()`하면 안 된다.
- 데이터 검사와 정제·변환·결합·분석은 분리해야 한다. 검사 함수는 원본이나 DataFrame을 변경하지 않고 진단 결과와 추천 사항만 반환하는 것이 안전하다.
- 데이터 결합은 `INSPECT → VALIDATE → DEFINE → PLAN → 사용자 승인 → EXECUTE → VERIFY → LOG` 순서로 진행하는 것이 적절하다.
- Key와 Grain은 자동으로 확정하지 않고 후보, 근거, 위험을 함께 제시해야 한다.
- `merge()` 후에는 행 수 변화, 매칭률, 미매칭 Key, 중복 증가, N:N 관계, Grain 불일치를 검증해야 한다.
- 데이터 분석 결과는 관찰·해석·활용·한계로 나누어 작성해야 하며, Python은 사실을 계산하고 AI와 사용자는 의미와 전략을 판단하는 역할을 맡는다.
