# 자가라벨링 방법론 적용 보고서

## 적용한 내용

- 24개 항목을 4개 그룹(자격·실적, 지역·경쟁제품, 금액·소기업, 공고·메타데이터)으로 나눠 관련 문서를 우선 검색한다.
- 공고문·첨부문서·나라장터 메타데이터를 함께 제공한다.
- 법령 검색 결과는 판단값을 직접 바꾸지 않고 근거 후보로만 제공한다.
- LLM이 출력한 근거는 원문 연속 문자열인지 검증하고, 원문에 없으면 제거한다.
- 구조화 JSON이 실패하면 compact/plain 복구 모드로 재시도한다.
- 자격조건·금액구간·품목유형·SW·예외를 `qualification_support.py`와 `decision_support.py`에서 독립적으로 분석한다.
- 부재탐지 항목은 근거 문구를 비워 제출 형식과 일치시킨다.

## 현재 적용되지 않은 항목

- 동일 입력을 여러 번 생성하는 고비용 self-consistency는 실제 대회 실행시간과 비용을 고려해 기본 실행에서는 사용하지 않는다.
- dev 라벨을 직접 학습해 예측값을 고정하는 방식은 리더보드 과적합 위험 때문에 사용하지 않는다.
- 최종 제출 전에는 반드시 대회 모델 환경에서 실제 `submission.csv`를 생성하고 preflight 검증한다.

## 검증 원칙

1. 모델 출력보다 공식 항목표와 법령·공고문 원문을 우선한다.
2. 특정 공고 ID나 dev 정답을 코드에 하드코딩하지 않는다.
3. 근거 없는 1 판정은 보정하지 않고, 불확실한 경우 모델 판단을 유지한다.
4. 제출 전 49개 컬럼, ID 중복, 0/1 값, 근거 길이·원문 일치 여부를 검사한다.
